Privacy Policy

Keyword Redact browser extension · Last updated 1 September 2026

Summary

Keyword Redact collects nothing, transmits nothing, and contacts no server. There is no analytics, no telemetry, no crash reporting, and no third-party service of any kind. Everything the extension does happens locally in your browser.

What the extension stores

The extension saves only your own settings:

  • your keyword list, including any replacement words you configure
  • your redaction mode and display preferences
  • the list of sites you have granted access to
  • your optional network-redaction URL patterns and JSON paths

This is stored using chrome.storage.local, which keeps the data on your machine. It is deliberately not stored with chrome.storage.sync, because syncing would copy your keyword list — by definition, the words you are trying to keep off your screen — to Google's servers. That choice is documented in the source at src/config.js.

What the extension does with page content

To redact keywords, the extension reads the text of pages on sites you have granted access to. That text is examined in memory, in your browser, only to find and cover matches. It is never stored, never logged, and never sent anywhere. Nothing about the pages you visit leaves your device.

If you enable the optional network-redaction feature, the extension also inspects responses from URLs matching patterns you supply, for the same purpose and under the same terms. This feature is off by default and does nothing until you both enable it and provide URL patterns.

Site access

The extension requests no site access when you install it. The install prompt asks for no host permissions at all, and the extension is inert until you explicitly grant a site from its popup. You grant access one origin at a time, and you can revoke it at any time from Chrome's extension settings — revoking takes effect immediately.

Data sharing

None. No data is sold, transferred, or shared with anyone, for any purpose.

Data retention

Your settings persist locally until you change them or uninstall the extension. Uninstalling removes them along with the extension. You can clear your keyword list at any time from the options page.

Remote code

The extension executes no remotely hosted code. All code ships inside the package and is reviewable in the public source repository.
