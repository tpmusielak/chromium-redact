Where it runs

One hostname per line. Subdomains are included.

Redaction happens in the page you are looking at. Anyone with access to this browser can read the original by opening DevTools, viewing source, or turning the extension off — so this is for screen sharing, demos and shoulder-surfing, not for withholding data from the person at the keyboard. Text drawn into canvas, video or images has no DOM and cannot be redacted. Substitute mode changes what a page appears to say, including for you — a plain substitution leaves no visible sign it happened, so turn the dotted underline on if you will be reading the page rather than only showing it.
